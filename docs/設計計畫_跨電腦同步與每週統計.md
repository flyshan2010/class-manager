## 1. 現況（2026-10-09 實查）

工作檢核台**本來就是雲端網頁**（GitHub Pages，`routine.html`），任何電腦開網址就能用、不必安裝。
換電腦會斷的是「存在瀏覽器 localStorage 的資料」：

| 資料（鍵） | 換電腦的後果 | 嚴重度 |
|---|---|---|
| 待送事件 `events.v1`（結算了還沒收班送出）| 留在舊電腦＝**沒送、沒入帳**；批次號不同步，計次類可能被去重吃掉 | 高 |
| 作業清點 `homework.v3`（欠交結轉 `carry`、補交 `madeUp`）| 欠交清單與補交追蹤消失 | 高 |
| 當天五站 `routine.v2`（含近 10 日快照）| 點到一半的格子、近 5 日出缺席不見 | 中 |
| 座號設定 `seats.v2` | 重填一個數字 | 低 |
| 白板小組計分 `groups.v1`、白板內容 `board.v1` | 當節分數、手寫內容不見 | 低 |

口令只存 sessionStorage（設計書 §3.4 不落地）——維持不變。

## 2. 同步設計

**原則**：localStorage 仍是工作正本（斷網照常用，硬規則 4）；雲端只是「跟著走的副本」，漸進增強。

- **儲存**：既有 Apps Script 代理的指令碼屬性（免新授權；單值 9KB 上限 → 分片）。只含座號與狀態，無姓名。
- **代理新增 3 個動作**（v2.11）：
  - `sync_pair`（驗教師口令）→ 回「裝置憑證」（代理首次自動產生的隨機字串，存指令碼屬性 `SYNC_SECRET`）
  - `state_get`／`state_put`（**只驗裝置憑證，不驗口令**）→ 讀寫 `{鍵: {v 值, rev 版次, at 時間, dev 哪台}}`
  - 憑證**只能讀寫檢核台狀態，不能加扣幣、不能送任務**；外洩時刪掉 `SYNC_SECRET` 即全部失效。
- **前端新增 `assets/js/sync.js`**（五頁共用；沒配對時完全不動作）：
  - 開頁：先照舊畫本機 → 背景 `state_get`。
  - 改動後 3 秒、與離開頁面時 `state_put`，帶「我上次看到的版次」。
  - **三種情況**（每個鍵各自判斷）：
    1. 本機沒改、雲端較新 → 自動帶入並重畫，角落提示「☁ 已接續另一台 12:05 的紀錄」
    2. 本機有改、雲端沒變 → 上傳
    3. **兩邊都改過** → 代理拒收（版次不合），畫面跳出「這台 12:10／另一台 12:05，用哪一份？」**不自動覆蓋**
  - 斷網／代理失敗：照舊只用本機，角落標「☁ 未同步」，恢復後補傳。
- **教師專區**：口令通過後自動配對（`sync_pair`），「班級座號」區塊下顯示同步狀態與「這台停止同步」。

**動錢安全（護欄 §1）**：同步的只是待送清單，入帳仍只有「老師按送出 → R18 依事件 id 去重」一條路。
規則類事件 id 不含批次號，兩台各送一次也只入帳一次；計次類（不動錢）靠同步批次號避免撞號。
驗證用既有 `scripts/sim-send.mjs` 模式加一支兩台模擬（A 送出後 B 接續、兩台同時改、斷網補傳）。
