# class-manager 設計藍圖與路線圖

> 教師支援系統**第二站**：班級管理系統（老師在教室投影用的課堂工具）。
> 上位規則：`Project/AGENTS.md`、`班級事務/CLAUDE.md`、本站 `class-manager/CLAUDE.md`。
> 三站架構：班網 class-website（家長學生・唯讀公開）／**班級管理系統 class-manager（老師・教室投影・本站）**／自學星圖 study-orbit（學生・自學，尚未建）。三站獨立 repo，共用 Notion 後台。

## 設計原則（動工前必守）
- **純靜態、零相依、斷網照常**：無 build、無 npm、無外部 CDN/字型。教室會斷網，斷網時全部工具照常可用。
- **連網只做漸進增強**：讀「同域名姊妹站」班網的公開 JSON（同源、免 token、不改班網檔）；先畫本機快取→再抓雲端→離線用快取。
- **只存座號、不存姓名**：座號在工作台設定（localStorage）；姓名/查詢碼/個資一個字都不寫。
- **寫入分級**：L1 即時只寫 localStorage（Phase 1 全部工具都在此級，不碰網路寫入）；L2 事件即時送出（尚未做）。
- **視覺基準**：參照「智慧教室儀表板 2.0」（apaulliao.github.io/schooltool）——近黑星空底、玻璃圓角卡片、彩色膠囊工具列。色票正本 `assets/css/{projection,style}.css` 的 `:root`。
- **投影版面**：1600×900、主要內容 ≥40px、深色高對比；**全站 RWD**（@media 900/560，390 寬須無橫捲）。

### 定案的五件事
1. **回寫管線＝複用既有 `submit_task`**（Apps Script 代理，token 不出 Script Properties），
   新增路由 **R18「批次事件包」**（任務原文 `#CM-EVENTS v1` ＋ JSON），排程 Agent 機械入庫。
   **後端零改動、不碰班網、延遲 ≤30 分。**
2. **常規檢核台 `routine.html`**（核心）：直接以班網公開的 `data/class-rules.json` 為骨架
   ——`cards` 10 張班規當事件目錄、`daily` 8 時段當分頁、**點完當場投影出 `fix` 修復方式給學生看**。
   打掃檢核＝其「環境晨掃」分頁（✓／△／✗ 三態，對上 class-bank 的 `基準＋支援−缺席`）。
3. **晨間報到板 `checkin.html`**：**只管上學到校**（上課遲到走常規檢核台的課堂分頁）。
   學生自己點，**機器只產生遲到候選、老師確認才成立**；不必開新 Notion 表，走紀錄庫。
   附帶好處：可機械算出班規①「一整週沒遲到 +10」，這個獎目前完全沒在發。
4. **座位加分板 `seatboard.html`**：版型＝班網座位表（需純座號版 JSON）；
   **只在 `teacher==="導師"` 的節次啟用**（科任課不開）；**依課表每節自動重置**，
   該節結束才把有次數的學生結成「舉手回答」事件。
   **輕點＝計次（不入帳，投影顯示當節次數供師生核對）**、**長按＝開班規選單才動錢**。
5. **唯一動錢的路徑是班規**。抽問／舉手一律「不論次數，每生每科每天一筆」，
   事件描述固定寫「座號N 在○○課舉手回答」，次數存欄位。
   （原設計每次入帳會讓單一學生一週拿到 +50 幣，商店券才 30–60 幣，班級經濟會崩。）

| # | 問題 | 修法 |

| 1 | 晨掃 △ 第一次就扣 −5，**違反既有制度**（1～2 次不扣幣只補做、3 次以上才 −5） | 改成 tally「打掃未達標」金幣 0，累計判斷交週結 |

**同日制度調整（老師裁示）**：

- **晨掃分三頁**（內掃區 23號／外掃區・圖書室 16號／外掃區・樓梯 19號），監督同學點自己那頁。
  **頁籤名不寫死**——取該監督各組組別名的共同字自動生成，改 Notion 掃區分組會跟著改。
- **本分項只記次數**：`DUTY_PAID` = ③good[0] 打掃本分、⑦good[1] 幹部職務本分（週薪已支付，
  再入帳就是同一件事付兩次）。**只限有工作薪水撐著的這兩張卡**——一刀切會把②有禮貌、⑤先聽完
  再回應那些沒有薪水對應的正向獎勵平白取消。⚠️ 兩張卡不在「上午課堂」時段，**要等 2-6 才有作用點**。
- ⑤「被記 2 個 ×」標明是**升級處分**（同一行為第 3 次才用），避免與個別扣點重複。
- 🔴 **金幣公式收成一條**：`正負向 × 程度 × 5`，**亮點類不再 ×10**。舊公式只算得出 10／20／30，
  對不上班規卡在用的 +5／+10／+15。「亮點」自此只是分類，不是第二套算錢方式。
- **幹部額外獎金不分名次一律 +15**（亮點・程度 3）、**進步獎 +20 → +5**（亮點・程度 1）。
  前者原本「第一名 30」與 R01 榮譽競賽規則的「幹部組 +10」**兩份規則對同一件事給不同金額**，一併統一。

改版後同一組亂數重跑：每人每週 **38.9 幣**（只有固定薪水是 37.0），通膨解除且沒變成通縮，商店價位不必動。
