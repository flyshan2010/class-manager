# 班級管理系統 · 老師操作手冊

網址：https://flyshan2010.github.io/class-manager/

## 第一次使用

1. 開啟網址 → 捲到「班級座號」。
2. 填班級人數就好，例如 `27`。按「儲存」，右上角會顯示「已設定 27 個座號」。
3. 有轉學生留下的空號時，改用逐段寫法，例如 `1-12,14-28`（跳過 13 號）。

**這裡不存學生姓名**，課堂工具一律用座號。設定只存在這台電腦的瀏覽器裡，
換電腦或清掉瀏覽器資料要重設一次（重設只要填一個數字，很快）。

## 課堂工具

Phase 1 六支工具**全部開放**。每支都全螢幕投影、深色高對比、教室後排看得清，
資料只留在這台電腦，**斷網照常可用**。共同操作：滑鼠停 3 秒下方工具列自動淡出、
`F` 全螢幕、右下角「← 工作台」回首頁。除計時外都要先在工作台設好座號。

- **電子看板**：直式聯絡簿＋值日生＋今日課表＋月相時鐘＋節慶倒數＋語音廣播（配字幕）＋計時，詳見下一節。
- **抽籤**：按「抽一位」或空白鍵，隨機抽一個座號。**每人限中一次**（抽過的自動排除），
  下方顯示剩幾人、已抽出誰；「重置名單」重新開始。抽完會提示。每天自動重置。
- **計時**：投影用大字倒數。按 `1/3/5/10/20 分` 或填自訂分鐘「起算」；`空白鍵` 暫停／繼續、
  `＋1 分` 加時、「歸零」清掉。剩 1 分鐘變橘、時間到閃爍響鈴。另有「正數計時」當碼錶。
- **抽籤問答**：抽一位同學回答，按「答對 ✓／答錯 ✗」（或鍵盤 →／←）累積分數，
  右側記分榜即時排名（優先抽被抽次數少的，較公平）。「重置分數」清空當天紀錄。
- **作業清點**：清點**前一天派的作業**（自動抓最近一個有作業的日子）＋聯絡簿，各項作業一頁全部列出，
  一眼看出哪份作業還有誰有問題。每個座號點一下換狀態：**未交→已交→要訂正→完成**，
  **一到「完成」座號就消失**，剩下的都是還要處理的。「顯示已完成」可回頭改、「全設未交」單項重來、「☁ 重讀作業」重抓雲端。
- **小組計分**：小組競賽計分板。「⚙ 分組設定」選組數（2–8）與分法
  （依座號連號／蛇形較平均／手動指定），可填組名。每組卡片按 `−1／＋1／＋5` 加減分，
  最高分那組亮起 👑。改分組不動分數，「分數全歸零」才清零。

## 今日待送（下課收班，一次送進紀錄庫）

課堂工具記下的加減分**先留在這台電腦**，不會馬上進 Notion；下課回工作台按一次「收班送出」才整批送出。
這樣做有兩個理由：課堂中不必等網路，斷網照記；而且送出前你還能先看一眼要送什麼。

1. 工作台「今日待送」會列出目前累積的事件（座號、行為、科目、次數、幣值）。同一位學生同一天同一件事會**自動合併成一列並算次數**。
2. 想先確認送出內容 → 按「預覽送出內容」，會顯示真正要送出的文字。
3. 確認沒問題 → 輸入教師口令（和教師專區同一組）→ 按「收班送出」。
4. 送出成功後清單會清空，排程 Agent（每小時整點跑）會把它們寫進「📝 班經與學習紀錄庫」。

**沒送出去也不會弄丟**：網路不通或口令打錯，畫面會說「待送 N 筆仍留在這台電腦」，稍後再按一次就好。
**按兩次也不會重複發錢**——每筆事件都有唯一編號，排程端查到重複就跳過。

⚠️ 只有工作台能送出，投影工具頁沒有送出按鈕、也不知道口令（避免投影時全班看到你打口令）。
⚠️ 「全部丟棄」會把待送事件整批刪掉且救不回來，確定不記錄才用。

## 電子看板

工作台點「電子看板」進去，直接投影給全班看。畫面參照「智慧教室儀表板」風格：
星空底、左上角**月相**、中間**民國日期**、右上角**今日值日生**與**時鐘**、
上方一排**今日課表**（各節課，正在上的那節會標黃），中央是**直式聯絡簿**，右下角**計時**，
月相日期旁是**節慶倒數**，值日生左邊是**午餐值週生**。日期那一行會寫出**星期幾**，
下一行小字是日期與**本週週次**（四上第N週）。

**午餐值週生**：讀班網公開的午餐輪值表（正本在 Notion「🧹 班級工作分配」），
**每週自動換一班**，跟班網「🌈 關於我們 → 工作分配」看到的是同一份，五個崗位（飯／菜1／菜2、3／湯1／湯2）各一張小卡。
輪到第幾輪由本週週次算出來（與班網同一條規則），**改 Notion 就會跟著改，看板這邊什麼都不用設定**。
姓名已去識別化（陳柏○）；這份名單**只在畫面上顯示、不存進這台電腦**（本系統不留學生姓名），
所以**斷網時會暫時不顯示午餐值週生**，其餘看板功能照常。

**語音廣播**：下方彩色鈕（回教室／走廊排隊／集合／安靜／準備下課）按下去會用內建語音唸出來，
斷網也能用；要唸自訂句子在「寫聯絡簿」面板最下面的「廣播」欄輸入。
**唸的同時畫面會出大字字幕**，講完才收（最短 3 秒，句子長就多留幾秒）——
這台電腦沒有中文語音時，學生照樣看得到，不會變成「按了沒反應」。
**上下課鐘聲**：面板「看板選項」勾「上下課自動鐘聲」，就會依課表時間到點自動響鈴，
字幕寫出**這節是什麼課、要先準備什麼**（例：「🔔 第三節 數學 上課了／鐘響前回教室 ➜ 擺課本文具、安靜坐好等指示」）。
科目取自班網課表，準備動作取自 Notion 班規的「每日流程 SOP」——**要改文字請到 Notion 改**，改完隔天自動生效。
**節慶倒數**：讀班網公開的節慶行事曆（正本在 Notion），**只顯示今天之後最近的一個**
（例：「🥮 中秋節連假 還有 19 天」），當天會寫「就是今天」，過了就自動換下一個。
顯示多個會讓學生一直想著放假，所以固定只出一筆。斷網時沿用上次讀到的內容。
> ⚠️ **「節慶倒數」和右下角的「計時」是兩件事**：前者算到節日還有幾天（資料在 Notion），
> 後者是上課用的分鐘計時器（按 `計時5分` 或鍵盤 `1`/`3`/`5`）。
**今日課表／月相**都自動依日期顯示，不用設定。

### 寫聯絡簿

按畫面下方的「寫聯絡簿」（或直接按鍵盤 `E`），在右側面板一行寫一項，按「寫上黑板」。
內容存在這台電腦，明天來還在，改掉就換新的。

**在家改、到校免重打（連網自動帶入）：** 你在家用 Notion「📒 聯絡簿」把當天那一列寫好
（或用平常的 class-admin 語音改），到學校打開這頁，**當天的作業／攜帶／提醒會自動出現在黑板上**，
不用在教室再打一次。面板下方會顯示「目前來源：雲端帶入（時間）」。
到校臨時想加一項，就直接在上面手改——**當天你手改過的內容，不會被雲端蓋回去**；
想改回雲端版按「用雲端版覆蓋」，想重抓最新按「☁ 重新讀取雲端」。
**教室斷網也照常可用**：連不上時就顯示上次存下的內容，不會變空白。

行首可以加符號：

| 寫法 | 效果 |
|---|---|
| `#國語` | 分隔標題（青色、不編號），用來分科目或分區塊 |
| `*明天小考` | 重點（黃色） |
| `~已經簽名` | 已完成（灰色劃掉） |
| 其他 | 一般項目，自動編號 |

項目多到一頁放不下時，字會自動縮小到剛好放得下（縮到教室後排看得清的下限 40px 為止）。
真的還是放不下，左下角會出現橘色提醒，這時請刪幾項或分兩次投影——**不要以為學生看得到**。

### 值日生

面板中段設定，三種方式：

- **自動輪值**（預設）：填「每天幾人」「基準日」「基準日當天從幾號開始」，
  之後每天自動往下輪，不必再進來。**只算平日**，週六日不推進。
  用的是工作台設定的座號，跳號的班級也會自動跳過空號。
- **手動指定**：直接填今天的座號，例如 `5, 6`。
- **不顯示**：整塊隱藏。

有人請假時按「今天順延一輪」，只影響今天以後，不用改基準日。

### 計時（右下角大字倒數）

畫面下方按 `1 分` `3 分` `5 分` `10 分`，或鍵盤按 `1` `3` `5`。
`空白鍵` 暫停／繼續，`0` 或「清除」收掉。剩 1 分鐘變橘色，時間到會閃爍並響三聲。
計時中版面下緣會自動讓開，數字不會壓到聯絡簿的字。

### 鍵盤

`E` 開關面板　`F` 全螢幕　`空白鍵` 計時暫停／繼續　`1`/`3`/`5` 起算　`0` 清除　`Esc` 關面板

滑鼠停住 3 秒，下方工具列會自己淡出，投影時畫面乾淨。動一下滑鼠就回來。

## 為什麼這個網站跟班網分開

班網是給家長和學生看的，這個網站是老師在教室裡用的。兩個是完全獨立的網站，
改這邊不會影響班網，這邊壞掉班網也照常運作。
