# 班級管理系統 · 老師操作手冊

網址：https://flyshan2010.github.io/class-manager/

## 第一次使用

1. 開啟網址 → 捲到「班級名單」。
2. 一行一位貼上名單，格式「座號 姓名」（例：`1 王小明`）。沒寫座號會依行序自動編號。
3. 按「儲存名單」，右上角會顯示「名單已載入 N 位」。

**名單只存在這台電腦的瀏覽器裡**，不上傳、不進版控。換電腦或清掉瀏覽器資料要重貼一次。

## 課堂工具

目前全部標示「準備中」，依施工計畫 Phase 1 陸續開放：
投影黑板 → 抽籤 → 計時 → 抽籤問答 → 作業播放表 → 小組計分。

## 為什麼這個網站跟班網分開

班網是給家長和學生看的，這個網站是老師在教室裡用的。兩個是完全獨立的網站，
改這邊不會影響班網，這邊壞掉班網也照常運作。
